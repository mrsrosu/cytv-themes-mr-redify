# cytv-themes

Personal themes for [Clean Your TV for LG webOS](https://github.com/Razdva122/clean-your-tv-lg-webos).

| Theme | ID |
| --- | --- |
| mr.redify | `github:mrsrosu/cytv-themes:mr-redify` |

## Install on the TV

Requires Clean Your TV Home **1.19.0 or newer**.

1. On the TV, open **Settings → Themes → Add by ID**.
2. Paste `https://github.com/mrsrosu/cytv-themes` and choose **Load**.
3. Pick **mr.redify**, download it, then select it in the Themes list.

### Exact link, pinned to a commit

If loading the repository address does not work, paste this link into **Add by ID → Load** instead. It points to a fixed commit and never changes:

```text
https://raw.githubusercontent.com/mrsrosu/cytv-themes/d68361366b8b2b0a67c63fc1d157ba524f474866/distributions/mr-redify/1.0.1/cytv-theme.json
```

Installed themes work offline. To remove one, choose **Remove** next to it in Themes (Classic is restored automatically).
