# mr.redify

A frosted-glass Home theme for LG webOS TVs running [Clean Your TV](https://github.com/Razdva122/clean-your-tv-lg-webos). It is derived from the bundled Liquid Glass theme: translucent dock and header buttons, a winter-night wallpaper, the Inputs menu in the header and all four weather formats.

Requires Home 1.19.0 or newer (as computed by the toolkit compiler; the theme declares `weather-v1`, `input-placement-v1` and `classic-motion-v1`). An older Home rejects it without changing your current theme.
